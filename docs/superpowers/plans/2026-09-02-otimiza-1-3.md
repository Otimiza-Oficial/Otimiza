Em `health.rs`, antes de `analisar_discos`:

```rust
/// O que se sabe sobre os erros acumulados de um disco.
///
/// TRÊS RESPOSTAS, E NÃO DUAS. `Some(0)` é "medi e deu zero"; `None` é "não
/// consegui medir". O código antigo somava com `unwrap_or(0)` e os dois viravam
/// a mesma coisa — um SSD que não publica o contador recebia atestado de saúde
/// que ninguém tinha medido.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ErrosDoDisco {
    Nenhum,
    Contados(u64),
    NaoSei,
}

pub fn avaliar_erros(leitura: Option<u64>, gravacao: Option<u64>) -> ErrosDoDisco {
    // Um lado ausente já impede saber o total: somar o que se tem com zero
    // seria inventar a metade que falta.
    let (Some(l), Some(g)) = (leitura, gravacao) else {
        return ErrosDoDisco::NaoSei;
    };

    match l + g {
        0 => ErrosDoDisco::Nenhum,
        total => ErrosDoDisco::Contados(total),
    }
}
```

E no lugar do `unwrap_or(0)` da linha 203, use `avaliar_erros(...)`:
- `Contados(n)` → o achado `Critical` que já existe hoje, com `n`.
- `Nenhum` → nada, como hoje.
- `NaoSei` → um achado de severidade `Ok` dizendo que **não foi possível ler** o contador deste disco, e que isso não é o mesmo que estar bem. Use `FixLocation::None`.

Em `thermal.rs`, o mesmo desenho:

```rust
/// O que se sabe sobre os limites de desempenho do processador.
///
/// Mesma razão do `ErrosDoDisco`: `Some(0)` é "medi e não há limite ativo";
/// `None` é "não consegui ler". Dizer que não há throttling sem ter medido é o
/// defeito no lugar mais caro, porque detectar throttling é o que este módulo
/// vende.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum LimitesDoProcessador {
    Nenhum,
    Ativos(u32),
    NaoSei,
}

pub fn avaliar_limites(flags: Option<u32>) -> LimitesDoProcessador {
    match flags {
        None => LimitesDoProcessador::NaoSei,
        Some(0) => LimitesDoProcessador::Nenhum,
        Some(f) => LimitesDoProcessador::Ativos(f),
    }
}
```

Faça `analyze()` usar isso e, no caso `NaoSei`, o texto do relatório deve dizer que **não foi possível medir** em vez de afirmar que está tudo bem. Não invente severidade nova: siga o que `decidir` já faz.
